# Contributing — CONSTRUCTOR AI

**Owner / Architect / Final Architectural Decision Authority:** Alexander Romaskevich (RomaskevicH). Development is founder-led with LLM assistance; tool-generated code and third-party dependencies require review and provenance records.

## Required changes

1. Use a focused branch / pull request when possible. Prefer a Conventional Commit scope.
2. Write or adjust executable tests for changed behavior; run `npm run verify`.
3. State the environment, commands, actual results, risks, limitations and rollback considerations.
4. Keep public/private boundaries: no personal data, access tokens, passwords or unreleased patent-sensitive internals.
5. Preserve existing history and copyright; do not forge authorship, test results or release statuses.
6. Do not describe an AI-generated application as verified until model→build→test→independent QA→approval is proven.
7. Security-sensitive actions, release and production deployment require owner approval.

`.github/CODEOWNERS` is advisory until an actual GitHub branch/ruleset review requirement is configured.

No open-source license has been granted in this repository at this time. External reuse requires appropriate permission; existing upstream licenses and lawful rights take precedence.
